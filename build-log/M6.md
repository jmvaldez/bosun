## Judgment calls

1. **Rollups.** Retention folds request rows past 400 days into `rollups` (one row per session, UTC day and model, priced at roll-up time with the table then current). Spend views show them as rows, so a session's `unattributed` does not jump when its old requests go; prompt-level detail for that history is gone by design. A re-ingest never re-inserts rows past the horizon. Day attribution of rolled history uses the UTC day.
2. **"7 days after end and ingest"** is implemented as: `ended_at` set, at least seven days old, and a full ingest finished after it ended.
3. **`ingest.json`.** The ledger writes the last full ingest time as a plain file as well, so `doctor` can read it without opening (and possibly creating) the database.
4. **What `doctor` can see.** It reads `~/.claude/settings.json` and the managed-policy files only; plugins installed at project or local scope, or via `--plugin-dir`, are not seen (as in the demo above).
5. **Purge safety.** `Remove` deletes only a dir equal to the resolved one, not a symlink, not `/` or `$HOME`, and either named `bosun` or set explicitly through `BOSUN_*_DIR`.
6. **`--purge-config`** implies `--purge`.
7. **Missing state dir** is a warning (the first hook creates it); an unwritable one fails.
