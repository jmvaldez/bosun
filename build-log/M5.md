## Judgment calls

1. **"tags ABC-123" for `run`.** The session does not exist when `run` executes, so the task travels as `BOSUN_TASK` (source `env`), set both with `new-window -e` and inside the command after the rc file. `bosun tag` is for a running session. With `--worktree` and no `--task`, the key parsed from the branch is used.
2. **Launcher.** The window runs `$SHELL -ic '<export PATH=<bosun dir>:$PATH; export BOSUN_TASK=KEY; <claude.launcher> <args>>'`; arguments after `--` are single-quoted. The launcher is not `exec`ed, so aliases and functions work; the window closes when the shell exits.
3. **Directory.** `--dir`, else the calling pane's path (`$TMUX_PANE`), else the working directory. If you run it from the demo wrapper without `--dir`, it falls back to the repo dir, which makes Claude ask to trust that folder.
4. **"Refuses a dirty target"** is implemented as refusing any existing target path, empty or not: it cannot touch anyone's files. git itself refuses a branch already checked out in another worktree, and the message is shown.
5. **Bare repositories** are refused (nowhere sensible "beside" them); set `run.worktree_dir` and use a normal clone.
6. **Branch names** become path pieces with `/` replaced by `-` (`feat/ABC-123` gives `api-feat-ABC-123`).
