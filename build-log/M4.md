# M4: popup

`bosun ui` (prefix + W) with the Agents and Spend tabs, peek, interrupt, CSV export and the version-gated popup binding in the generated conf. tmux 3.2a, so the binding takes the no-title branch (D-3). Raw mode uses `unix.IoctlGetTermios` / `IoctlSetTermios` with per-OS request constants (`term_linux.go`, `term_darwin.go`, darwin cross-built and vetted). `go vet`, `go test ./...`, `go test -short ./...`, `make cross`, and `BOSUN_TEST_TMUX=1 go test ./...` are green.

## Judgment calls

1. **Model and terminal are separate.** `Model.View` is a pure function of data and size and returns exactly `h` lines of exactly `w` columns, so every layout rule is asserted on strings. The real terminal behaviour (raw mode, redraw, resize, escape decoding) is covered by the pty and tmux tests.
2. **Pane-gone sessions** are listed last with `? pane gone` and a disabled `enter`, but never counted. Sessions with no tmux locator at all are not listed.
3. **`unattributed`** is shown both under each session in the tree and as one summary row below it; the BY MODEL list includes it so that it sums to TOTAL.
4. **Ingest on open.** The popup runs the same incremental ingest as `spend` when it opens and every 30 s, and reloads the ledger every 5 s; the evaluator runs every second.
5. **Interrupt is the only pane write** and re-checks the server pid, the pane id, the process start token, and that the session's process is the pane's process or a descendant of it, right at the moment of `y`. Any failure prints `pane changed, not sent`.
6. **`x`** dismisses every active alert of the row's session, or only the subagent's when a subagent row is selected, then retracts their notices.
7. **Key `a`** jumps to the head of the waiting queue; unlike `prefix + a` it does not walk.
8. **Window title on tmux 3.2** is absent by design (D-3); on 3.3 and later the binding adds `-T ' bosun '`.
